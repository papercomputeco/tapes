# Dagger Version Update

Keep these aligned:

- `flake.lock`: pins the `dagger/nix` CLI and Engine version. 
  Update this using `nix flake update dagger`.
- `dagger.json`: sets the Dagger module's `engineVersion`.
- `.dagger/go.mod` and `.dagger/go.sum`: generated by `dagger develop`.
- `.github/workflows/*.yaml`: install Nix, enable the Nix cache, and run Dagger 
  with `nix develop --command` directly.
- Remote daggerverse references: pin them to immutable, compatible commits.

Update steps:

1. Upgrade the `dagger` flake input with `nix flake update dagger`.
   Typically, this should be the latest Dagger release.
2. Run `nix develop --command dagger develop` to upgrade the Dagger module's
   `.dagger/go.mod` and `.dagger/go.sum`.
3. Confirm `nix develop --command dagger version` matches `dagger.json`.
4. Review the generated `.dagger/go.mod` and `.dagger/go.sum` changes. 
   Do NOT edit them manually.
5. Check that CI uses `nix develop --command dagger ...` and has no separate 
   `DAGGER_VERSION` or Dagger install action step.
6. Run `nix flake check`, `nix develop --command make format`, 
   and `nix develop --command make check` as a final validation.
